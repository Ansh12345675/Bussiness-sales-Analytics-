# Business Sales Analytics Dashboard

A Business Sales Analytics project using Power BI and SQL to explore sales performance and generate business insights.

## Project Overview
This project analyzes sales data of 500 orders to understand revenue, profit, costs, product categories and regional performance.

## Tools & Technologies
- Microsoft Power BI
- SQL Server (SQL scripts provided)
- DAX
- CSV Dataset

## Dashboard Features
- Total Revenue
- Total Profit
- Total Cost
- Total Orders
- Total Quantity
- Monthly Revenue Trends
- Year-wise Revenue Analysis
- Category-wise Sales Analysis
- Region-wise Revenue Analysis

## How to Run
1. Download or clone this repository.
2. Open the SQL scripts in SQL Server Management Studio.
3. Execute the schema and seed script.
4. Execute the analysis queries.
5. Open `Business_Sales_Analytics.pbix` in Power BI Desktop.
6. Explore the dashboard visuals.
